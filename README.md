# 琴：遗失的和弦

一个以音乐史调查、场景探索、传闻勘误、梦境与图像残页为核心的静态网页游戏框架。

- `index.html`：游戏入口
- `editor.html`：内容编辑页
- `content.js`：可替换的游戏内容
- `styles.css` / `game.js`：游戏界面与玩法
- `assets/weilan-empire-map.svg`：维兰帝国游戏地图

地图地点会按照 `requiredKeyClues` 逐步解锁。未开放区域覆盖暗幕，地点开放时会从对应坐标向外照亮；地点坐标和照亮范围可以在编辑页的“地点与场景”中直接拖动调整。

## 当前完整流程

1. 导师邮件说明研究身份，并解锁第一个地点。
2. 玩家在场景图上寻找调查点；每条记录可打开“配图 + 完整正文”纸页。
3. 地点随关键线索数逐步解封，全部调查完成后会改变地图点位颜色。
4. 调查中途触发梦境；现实进度会更新梦境线索，并在满足条件后开放黑／白稿切换。
5. 玩家用相悖证据逐条更正传言。
6. 五页图像残页按各自里程碑逐页复原；全部解锁后可连续阅读。
7. 最后进入完整历史正文，并自动播放感谢名单。

## 以后填内容时

- 在 `editor.html` 中编辑文字、地点、场景、调查点、梦境、漫画、正文与名单。
- 场景、梦境和漫画都可以先选择本机图片预览；这种预览不会写入草稿，也不会上传。
- 正式图片上传到仓库后，把路径填成类似 `assets/scenes/archive-01.jpg`、`assets/clues/clue-01.jpg`、`assets/dream-black.jpg` 或 `assets/comics/page-1.jpg`。
- 地图底图可以随时替换；换成 Mapgen4 导出的新地图后，再在编辑页拖动地点即可，不需要重做玩法。
- 完成编辑后点击“生成更新文件”，将下载的 `content.js` 替换到仓库根目录。

本项目不需要服务器或账号系统，调查进度保存在玩家当前设备的浏览器中。
