# 琴：遗失的和弦

一个以音乐史调查、场景探索、时间线复原与梦境为核心的静态网页游戏框架。

- `index.html`：游戏入口
- `editor.html`：内容编辑页
- `content.js`：可替换的游戏内容
- `styles.css` / `game.js`：游戏界面与玩法
- `assets/weilan-empire-map.svg`：维兰帝国游戏地图

地图地点会按照 `requiredKeyClues` 逐步解锁。未开放区域覆盖暗幕，地点开放时会从对应坐标向外照亮；地点坐标和照亮范围可以在编辑页的“地点与场景”中直接拖动调整。

本项目不需要服务器或账号系统，调查进度保存在玩家当前设备的浏览器中。
